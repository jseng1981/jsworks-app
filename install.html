J&S Works 앱 설치

한 번만 설치하면 됩니다. 업데이트는 자동으로 됩니다.

바로 설치

설치 없이 열기

아래에서 내 기기에 맞는 방법을 따라 하세요.

✓ 이미 앱으로 실행 중입니다.

안드로이드 휴대폰 내 기기

  1. 크롬으로 이 페이지(app.jsec.co.kr)를 엽니다.
  2. 위의 앱 설치하기 버튼을 누르거나, 오른쪽 위 ⋮ → 앱 설치 (또는 홈 화면에 추가)
  3. 홈 화면의 J&S Works 아이콘으로 엽니다.

삼성 인터넷: 아래 ≡ → 현재 페이지 추가 → 홈 화면

아이폰 · 아이패드 내 기기

  1. 사파리로 이 페이지를 엽니다. (카카오톡에서 열었다면 오른쪽 아래 ⋯ → Safari로 열기)
  2. 아래 가운데 공유 □↑ 버튼 → 아래로 내려 홈 화면에 추가
  3. 오른쪽 위 추가 → 홈 화면의 J&S Works 아이콘으로 엽니다.

PC (윈도우 · 맥) 내 기기

  1. 크롬 또는 엣지로 이 페이지를 엽니다.
  2. 주소창 오른쪽의 설치 ⊕ 아이콘 → 설치
    아이콘이 안 보이면: 크롬 ⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치 / 엣지 ⋯ → 앱 → 이 사이트를 앱으로 설치
  3. 바탕화면 · 시작 메뉴(맥은 Launchpad · Dock)의 J&S Works 아이콘으로 엽니다.

맥 사파리: 메뉴 파일 → Dock에 추가

알아 두세요

  1. 앱에서 처음 한 번 로그인합니다 (기기마다 따로).
  2. 시스템이 업데이트되면 앱을 다시 열기만 하면 최신 화면입니다. 새 링크를 받을 필요가 없습니다.
  3. 사진 촬영 · 녹음을 처음 쓸 때 권한 허용을 물으면 "허용"을 누르세요.
  4. 화면이 이상하면 앱을 완전히 닫았다가 다시 여세요.
